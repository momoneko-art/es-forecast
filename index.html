このシステムの仕組み

  • GitHub Actionsが15分ごとにPSKReporter(FT8実伝播データ・10m/6m帯)とNOAA宇宙天気(Kp指数)を実測取得し、このリポジトリに書き戻しています。
  • 各地点の指数は「季節・時刻の統計モデル(気候学的ベースライン)」に「実際のFT8伝播観測(=Esで短距離オープンした証拠)」を上乗せして算出しています。実伝播が観測できた時間帯ほど数値の信頼度が上がります。
  • データが十分に蓄積されると(目安60サンプル=15時間分)、Ridge回帰モデルが自動学習され、統計的な「通常より多い/少ない」を判定に使うようになります。
  • NICTのイオノゾンデ実測値（各地点のfoEs＝E層臨界周波数、15分更新）が取得できた場合は最優先の証拠として扱い、PSKReporterの実伝播報告と合わせて指数を押し上げます。取得できない時間帯は統計モデルとPSKReporterのみで代替します。最終確認は必ず上記リンクの公式データで行ってください。
  • NOAAの3日先までのKp"予報"も取得しており、稚内(オーロラ帯に近い高緯度局)については、実測Kpがまだ上がっていなくても向こう24時間以内に地磁気嵐の到来が予報されていれば、それを見込んで指数を先行して押し上げます(カードに「地磁気嵐接近中(予報)」バッジが出ます)。中低緯度の3局はこの予報の影響をほぼ受けません(オーロラ性Esとの関連が薄いため)。
